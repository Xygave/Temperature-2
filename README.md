# Temperature 1.1.0 — Paper 1.21.11

Сборка: загрузите содержимое этой папки в ветку `develop` на GitHub; GitHub Actions соберет jar.

Требования: Java 21, Paper 1.21.11; WorldGuard 7.0.13 (необязателен, но нужен для флага).

Команды: `/temperature`, `/temperature on`, `/temperature off`, `/temperature reload`.

Флаг WorldGuard: `/rg flag spawn temperature-effects deny` (отключить эффекты на спавне).

Настройки после первого запуска: `plugins/Temperature/config.yml`.

Важно: новая версия не тестировалась на реальном сервере. Проверьте GitHub Actions и консоль Paper перед использованием на основном сервере.
